## 2. Art Direction Styles (20+)

1. **Minimalist** — White space dominant, single focal element, 1-2 colors, clean sans-serif type
2. **Bold Typography** — Type IS the design; oversized, expressive letterforms fill the canvas
3. **Gradient / Color Wash** — Smooth color transitions, mesh gradients, chromatic blends
4. **Photo-Based** — Full-bleed photography with text overlay; hero lifestyle imagery
5. **Illustrated / Hand-Drawn** — Custom illustrations, bespoke icons, artisan feel
6. **Geometric / Abstract** — Shapes, lines, grids as primary visual elements
7. **Retro / Vintage** — Distressed textures, muted palettes, serif type, halftone dots
8. **Glassmorphism** — Frosted glass panels, blur backdrop, subtle border glow
9. **3D / Sculptural** — Rendered objects, depth, shadows; product-centric
10. **Neon / Cyberpunk** — Dark backgrounds, glowing neon accents, high contrast
11. **Duotone** — Two-color photo treatment; bold brand color overlay on image
12. **Editorial / Magazine** — Grid-heavy layouts, pull quotes, journalistic composition
13. **Collage / Mixed Media** — Cut-paper textures, photo cutouts, layered elements
14. **Retro Futurism** — Space-age nostalgia meets bold palettes; chrome, gradients, optimism
15. **Expressive / Anti-Design** — Chaotic layouts, mixed fonts, deliberate "wrong" composition
16. **Digi-Cute / Kawaii** — Rounded shapes, pastel gradients, pixel art, playful characters
17. **Tactile / Sensory** — Puffy/squishy textures, hyper-real materials, embossed feel
18. **Data / Infographic** — Stats front-and-center, charts, numbers as heroes
19. **Dark Mode / Moody** — Near-black backgrounds, rich jewel tones, high contrast
20. **Flat / Solid Color** — Single background color, clean icons, no gradients
21. **Nature / Organic** — Earthy tones, botanical motifs, sustainable brand feel
22. **Motion-Ready / Kinetic** — Designed for animation; layered elements, loopable compositions

## 3. Design Principles for Banners

### Visual Hierarchy (3-Zone Rule)
- **Top zone** — Logo or main value prop (visible at distance)
- **Middle zone** — Supporting message + visuals
- **Bottom zone** — CTA (button/QR/URL)

### Safe Zones
- Keep critical content in **central 70–80%** of canvas
- Avoid placing text/CTA within 50–100px of edges
- YouTube: use 1546 × 423px safe area inside 2560 × 1440 art
- Meta/Instagram: safe zone = central 80% to avoid UI chrome

### CTA Best Practices
- One CTA per banner — never more
- High contrast vs. background (not brand color if it blends)
- Place at **bottom-right** (terminal area; last natural eye stop)
- Button: min 44px tall for tap targets on mobile
- Action verbs: "Get", "Start", "Download", "Claim"

### Typography
- Max 2 typefaces per banner
- Min 16px body text; headline ≥ 32px for digital
- Dark text on light bg (or vice versa) — min 4.5:1 contrast ratio
- Limit copy to **7 words per line**, **3 lines max** for ads

### Text-to-Image Ratio
- Ads: keep text under 20% of canvas (Facebook still penalizes heavy text)
- Social covers: 60/40 image-to-text or more image-heavy
- Print banners: readability at 3–5 meters; use 70pt+ headlines

### Brand Consistency
- Use brand color palette as defined in brand guidelines
- Logo in consistent position (top-left for most formats)
- Maintain font family across all banner variants

## 4. Tips by Banner Purpose

### Social Media Covers
- Design for mobile-first crop
- Keep face/logo away from left edge on Facebook (profile pic overlaps)
- Use video loops (YouTube supports animated channel art)
- Refresh seasonally for engagement signal

### Display Ads
- A/B test 300×250 + 728×90 + 160×600 minimum set
- Animation: max 30s, max 3 loops, max 150KB file size
- Prefer Google Responsive Display Ads for reach
- Single clear message — no paragraph text

### Website Hero Banners
- Full-bleed at 1920px wide; ensure design works at 1280px
- Contrast text over photo using overlay or text-shadow
- Include above-fold CTA (visible without scroll)
- Optimize: WebP format, <200KB for fast load

### Print / Event Banners
- Design at 300 DPI minimum; 150 DPI acceptable for large format
- Add 3–5mm bleed all sides
- Use CMYK color mode (not RGB)
- Test legibility at intended viewing distance (1ft rule: 1pt per foot)

## 5. 2025–2026 Trending Patterns

- **Tactile rebellion** — Imperfection, grain, hand-touch over AI-smooth
- **Retro futurism** — Bold optimistic color + nostalgic retrofuture aesthetic
- **Expressive type** — Type as hero; oversized, distorted, bubbly letterforms
- **Digi-cute** — Kawaii-inspired digital characters, pixel art integration
- **Anti-AI aesthetic** — Intentional roughness, artisanal marks, visible process
- **Motion-first** — Static banners designed with animation layers in mind
- **Responsive/adaptive** — Single source design exported at all sizes (Google RDA pattern)
