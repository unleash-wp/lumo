## Shader Techniques Used

### Fractional Brownian Motion (fBm)
```glsl
float fbm(vec2 st) {
  float value = 0.0;
  float amplitude = 0.5;
  for (int i = 0; i < 5; i++) {
    value += amplitude * noise(st);
    st *= 2.0;
    amplitude *= 0.5;
  }
  return value;
}
```

### Animated Grid Pattern
```glsl
vec2 grid = fract(st * 8.0 + u_time * 0.05);
float lines = step(0.95, grid.x) + step(0.95, grid.y);
```

### Wave Distortion
```glsl
float wave1 = sin(st.x * 4.0 + u_time * 1.5) * 0.15;
float wave2 = sin(st.x * 8.0 - u_time * 1.2) * 0.08;
```
