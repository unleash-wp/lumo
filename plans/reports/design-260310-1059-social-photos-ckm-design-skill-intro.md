# Social Photos Design Report: /ckm:design Skill Introduction

## Overview
- **Prompt:** Social photos introducing the `/ckm:design` unified design skill
- **Platforms:** Instagram Post (1080×1080), LinkedIn Post (1200×627), X/Twitter Post (1200×675)
- **Variations:** 3 concepts × 3 sizes = 9 images
- **Style:** Dark mode, Ocean Professional (brand-aligned)

## Ideas Generated

### Concept 1: "Design Everything"
Feature grid layout — 8 capability cards (Logo, CIP, Slides, Banners, Social, Icons, Brand, Tokens) in a 4×2 grid. Clean, informative, scannable at thumbnail size. Best for: product overview posts, feature announcements.

### Concept 2: "One Command. Full Design."
Bold typography hero — centered layout with terminal command box, rainbow gradient title, and colored capability pills. Highest visual impact. Best for: announcement posts, viral potential, engagement-first.

### Concept 3: "AI Design Studio"
Terminal aesthetic — split layout (terminal left, content right) showing actual `/ckm:design` commands with success outputs. Developer-oriented, authentic. Best for: dev communities, Twitter/X tech audience, LinkedIn thought leadership.

## Design Decisions

| Decision | Choice | Why |
|----------|--------|-----|
| Color palette | Ocean Blue #3B82F6, Gold #F59E0B, Emerald #10B981, Purple #9B5DE5, Coral #FF6B6B | Brand guidelines — dark-mode first "Ocean Professional" |
| Typography | Space Grotesk 700 (headings), JetBrains Mono (code/badges) | Brand fonts — professional yet technical |
| Background | #0D0D0D → #1A1A2E gradient | Brand dark mode palette |
| Card borders | Color-coded per capability | Visual differentiation; draws eye across grid |
| Command box | Terminal-style with green prompt | Authentic dev tool aesthetic; shows real usage |

## Why This Works

- **Brand alignment:** 100% adherent to Ocean Professional dark-mode identity — colors, fonts, gradients, spacing all from `docs/brand-guidelines.md`
- **Platform optimization:** Each size adapted for its platform — IG square centered, LinkedIn/X landscape with split layouts for readability
- **Visual hierarchy:** Single focal point per design — title → subtitle → supporting elements. Readable at feed thumbnail size
- **Developer audience:** Terminal aesthetic (Concept 3) and command boxes (Concept 2) resonate with target persona (indie hackers, dev teams)
- **Feature communication:** All 8 design capabilities visible at a glance without overwhelming — grid (C1), pills (C2), or output cards (C3)
- **Text <20%:** Compliant with Meta ad text guidelines for potential paid promotion

## Recommendations

- **A/B test:** Concept 2 (bold typography) vs Concept 3 (terminal) on X/Twitter — both appeal to dev audience differently
- **Instagram:** Use Concept 1 (grid) for carousel first slide; follow with individual capability deep-dives
- **LinkedIn:** Concept 3 (AI Design Studio) performs best — professional + technical, thought leadership angle
- **Iteration:** Consider animated GIF version of Concept 3 with typing animation for higher engagement
